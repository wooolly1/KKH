# 💩 صاحبي الخرا (Poop Buddy)

لعبة بسيطة: سوّي حساب، اصنع شخصية 💩 حقك، أرسلها لحبيبك يعتني فيها، وتوصلك إشعارات لحظة ما يكون جالس يهتم فيها.

## استضفها بضغطة زر

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/wooolly1/KKH/tree/claude/poop-character-game-gnmtus)

اضغط الزر → سجّل دخول أو أنشئ حساب Render مجاني → يقرأ إعدادات `render.yaml` تلقائيًا وينشر الموقع. بعد دقيقة أو دقيقتين بيعطيك رابط حقيقي (`https://poop-buddy.onrender.com` أو شبيه) تقدر ترسله لحبيبك يفتحه من جهازه.

**ملاحظة عن الخطة المجانية بـ Render:** ما فيها قرص تخزين دائم، فبيانات اللعبة (`data/db.json`) ترجع فاضية كل ما الخدمة تعيد التشغيل — وهذا يصير تلقائيًا بعد 15 دقيقة من عدم الاستخدام، وأيضًا مع كل نشر جديد. يعني الحسابات والخرو تنمسح بين فترة وثانية. لو تبيها تحتفظ بالبيانات بشكل دائم، رقّي الخدمة لخطة مدفوعة من لوحة Render وأضف قرص (Disk) يتربط بمسار `data/`.

## المميزات

- تسجيل دخول / حساب جديد (كلمات مرور مشفّرة بـ bcrypt).
- استوديو بناء الخرا: اختيار لون، هالة، وإكسسوار، مع معاينة حية.
- إرسال الخرا لأي مستخدم ثاني (بواسطة اسم المستخدم) عشان يعتني فيها.
- من يستلم الخرا يقدر يطعمها 🍔، يلعب معها 🎮، وينظّفها 🧼 — كل عملية ترفع إحصائياتها.
- الإحصائيات (جوع/مزاج/نظافة) تنخفض تدريجيًا مع الوقت لو محد اعتنى فيها.
- إشعارات لصاحب الخرا الأصلي كل ما حبيبه يعتني فيها، مع جرس إشعارات يتحدّث تلقائيًا (polling) وتنبيهات منبثقة.

## التشغيل محليًا

```bash
npm install
npm start
```

يفتح السيرفر على `http://localhost:3000`.

للتطوير مع إعادة تشغيل تلقائية عند التعديل:

```bash
npm run dev
```

## كيف تلعب

1. سوّي حساب من `/register`.
2. من لوحتك اضغط "اصنع خرا جديد" وصمم شخصيتك.
3. افتح صفحة الخرا واكتب اسم مستخدم حبيبك في مربع الإرسال.
4. حبيبك يسجل دخول، يشوف الخرا تحت "خرو تعتني فيها لحبايبك"، ويبدأ يعتني فيها.
5. كل عملية اعتناء ترسل لك إشعار فوري إنه جالس يعتني بخراك 💞.

## التقنيات

- Node.js + Express + EJS (رندر من طرف السيرفر، بدون بناء واجهة معقّد).
- تخزين البيانات في ملف JSON محلي (`data/db.json`, يتكوّن تلقائيًا) — بدون أي اعتمادية على قاعدة بيانات خارجية.
- جلسات مستخدم عبر `express-session`.
